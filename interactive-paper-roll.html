Interactive Paper Roll

URP HLSL Custom GUI C# Tooling

Project Overview

A procedural shader system created for Unity's Universal Render Pipeline (URP) designed to construct interactive 3D scrolls, maps, and ancient manuscripts. It delivers real-time rolling animations, organic edge weathering, dynamic burning, and wave deformation, fully manageable through high-level C# scripts.

Technical Implementation

  • HLSL Vertex Deformation (Rolling Simulation): Uses tailored HLSL math to calculate non-linear vertex curl and curvature in real time on the GPU. Provides four distinct roll modes: Top, Bottom, Both (Symmetrical), and Both (Independent), ensuring support for single scrolls or dual-spindle rolled maps.
  • Organic Edge Erosion & Burn Effects: Features procedural noise erosion for authentic torn paper borders, dynamic wave displacement for subtle physical movement, and customizable dissolve/burn effects with glowing ember outlines. Supports independent front and back textures to simulate illustrations, writing, or backing parchment.
  • Custom Material GUI: Includes an intuitive Unity Editor custom shader inspector that cleans up clutter, presenting artists with neatly categorized property groups, visual toggles, and sliders.
  • C# Paper Controller: Ships with an out-of-the-box C# Controller script allowing programmers and technical designers to animate, unroll, curl, and burn the paper at runtime via scripts, UI events, or Unity Timelines without needing to know shader internals or manipulate material properties by hand.
