Screen-Space Frost Effect

URP Post-Processing Refraction

Project Overview

A FullScreen post-processing shader for URP that simulates a frozen camera lens. It applies a custom frost texture authored in Substance Designer as a stylized vignette, while deforming screen normals so that underlying light is refracted through the ice layer.

Technical Implementation

  • Normal Refraction: Instead of just overlaying a texture, the shader utilizes normal mapping to deform and refract the underlying screen texture, creating a convincing icy distortion.
  • Editor Tooling: Developed a custom Editor Window (Tools -> Install / Uninstall FrostFX) that automatically detects the active URP RenderData and injects or removes the ScriptableRenderFeature, preventing users from having to navigate complex rendering assets.
  • Customization: Fully exposed properties for snow coloration, frost intensity, and distortion scale.
