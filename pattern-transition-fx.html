Pattern Transition Screen FX

URP Shader Graph C# Tooling

Project Overview

FullScreen effect for Unity URP that transitions between the rendered scene and a flat color. Patterns—both 2D and 3D—are projected onto the scene geometry using Triplanar Mapping, creating seamless coverage regardless of surface orientation.

Technical Implementation

  • Decoupled Architecture: Built using a Scriptable Object pattern. Variants (SO Profiles) can be created to define Unity curves, custom timings, and behavior without hardcoding logic into the MonoBehaviours.
  • Custom API: A simple and robust API (Play, Reverse, SetProgress) allows gameplay programmers and UI systems to trigger and control the effect without dealing with shader properties directly.
  • Automated Tooling: Includes a custom Unity Editor script that automatically installs and injects the required RenderFeature into the active URP RenderData, eliminating manual setup errors.
